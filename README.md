# 🎲 Dice Roller

A sleek, modern, and responsive web application for tabletop gamers and enthusiasts to roll dice and track results effortlessly.

## ✨ Features

- **Quick Roll:** One-click rolling for standard polyhedral dice (D4, D6, D8, D10, D12, D20, D100).
- **Custom Rolls:** Support for notation like `2d6` or `3d10` for complex tabletop requirements.
- **Coin Flip:** A quick way to settle decisions with a single click.
- **Statistics:** Real-time tracking of your rolls, including Total, Sum, Average, and Max values.
- **Roll History:** Keep a log of all your previous rolls with timestamps.
- **Export Data:** Easily export your roll history for later analysis.
- **Dark Mode:** Built-in theme switcher to suit your gaming environment (Light/Dark mode).
- **Responsive Design:** Works beautifully on desktops, tablets, and mobile devices.
- **Keyboard Shortcuts:** 
  - Use keys `1` through `7` for quick dice selection.
  - Use the `Spacebar` for instant coin flips.

## 🚀 How to Use

Simply save and open `dice.html` in any modern web browser.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (using CSS Variables for theming)
- **Vanilla JavaScript** (No heavy frameworks, just pure, fast performance)
